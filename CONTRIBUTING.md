# Contributing

Help keep Frontend Toolchain useful and current by suggesting resources, fixing stale links, and improving descriptions.

## Add a resource

Before adding a link, check that:

- It helps with building, testing, or shipping frontend experiences.
- The project is maintained, and the link opens the intended page.
- The entry adds value beyond resources already in the same section.
- Its description explains what it helps a developer do, rather than using promotional claims.
- The resource is placed in the most relevant existing section. Propose a new section only when several useful entries need it.

Use this format:

```markdown
- [Resource name](https://example.com/) — A short, factual description of the task it helps with.
```

If a resource is paid, requires an account, or has a meaningful limitation, mention that when it affects whether a developer can use it.

## Update or remove a resource

Please include the reason for an update or removal, such as a dead link, discontinued product, duplicate, or outdated description. A temporary outage or rate limit alone is not enough to remove a resource.

## Pull requests

- Keep changes focused and descriptions concise.
- Use English for resource names, descriptions, documentation, and commit messages.
- The link checker runs for pull requests and on a schedule. Review its report; automated checks can be affected by rate limits or bot protection.
